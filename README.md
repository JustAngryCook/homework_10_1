# Модули с функциями для работы с банковскими картами и счетами
## Модуль "widget" показывает информацию о карте/счете, дату и время
## Модуль "masks" маскирует номер карты и счета
## Модуль "processing" сортирует операции по дате и по параметру "выполнено/отказано"
## Модуль "generators" сортирует транзакции по заданной валюте, предоставляет описание операций и генерирует номера банковских карт
## Модуль "decorators" логирует время и результаты выполнения функции в файл, либо консоль
## Модуль "utils" принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях
## Модуль "external_api" извлекает сумму из транзакции и возвращает как float, конвертирую в рубли
## Модуль "reading_transactions_from_databases" считывает финансовые операции из файлов csv и xlsx
